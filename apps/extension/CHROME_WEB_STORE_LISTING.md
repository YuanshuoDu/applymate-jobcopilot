# ApplyMate AI — Chrome Web Store submission draft

Use this document when completing the Chrome Web Store Developer Dashboard. The upload artifact is generated by `pnpm build` followed by `pnpm zip`.

## Store listing

- **Name:** ApplyMate AI
- **Short description:** Save jobs, match your profile, and fill application forms with AI-assisted review.
- **Category:** Productivity
- **Language:** English
- **Website:** https://applymate.site
- **Privacy policy:** https://applymate.site/privacy

### Full description

ApplyMate AI is an AI-assisted job application copilot for saving jobs, matching your resume and Persona, and reviewing form-fill suggestions.

Use it on LinkedIn, Indeed, Greenhouse, Lever, Workday, and supported employer career pages to:

- save the current job to your ApplyMate account;
- match a saved job with your resume and profile;
- open the ApplyMate side panel for job, resume, and form tools;
- scan application forms, including custom company forms and cross-frame ATS forms;
- review and edit AI suggestions before filling fields; and
- choose local files yourself when a resume or document upload is needed.

ApplyMate does not submit applications for you. You remain in control of every filled value and the final submission.

When you start a form scan, ApplyMate reads field labels and any existing values on the selected page. The relevant data is sent securely to ApplyMate to generate the requested suggestions. Optional access to other websites is requested only when you choose to use form filling there. See the privacy policy for details.

## Permission justifications

- **Storage:** Keeps account-scoped extension settings, current job state, and saved-job cache synchronized between Popup, Side Panel, and the service worker.
- **Side Panel:** Provides the ApplyMate application workspace.
- **Active tab:** Reads the page the user is actively working on for the requested job or form action.
- **Scripting:** Injects the form scanner/filler into the user-selected page and its accessible frames after the user starts the feature.
- **Tabs:** Tracks the active page, restores the requested UI after navigation, and synchronizes an authenticated ApplyMate dashboard tab.
- **Context menus:** Provides the optional “Save to ApplyMate” context-menu action on supported pages.
- **Known job-site host permissions:** Enables job detection and the Save to ApplyMate action on the listed job boards and ATS hosts.
- **ApplyMate host permission:** Connects the extension to the ApplyMate API and authenticated dashboard.
- **Optional `http://*/*` and `https://*/*`:** Enables form scanning on a company career site or ATS host that is not in the built-in host list. The permission is requested at runtime from the Form auto-fill panel, not during installation, and is used only after the user starts that feature.

## Data disclosure answers

- **Does the extension handle user data?** Yes.
- **Data types:** Authentication/account information, job-page content, resume/Persona data, application form field labels and values, extension settings, and supported-page URLs.
- **Purpose:** User-requested job saving, matching, AI-assisted form suggestions, and reviewed form filling.
- **Data sharing:** Relevant data is sent over HTTPS to ApplyMate services and, only when an AI feature is requested, to the configured AI provider to return that result.
- **Selling or advertising:** No sale of personal data and no personalized advertising.
- **Human access:** No routine human access to user content; exceptions are limited to user-directed support, security, legal compliance, or aggregated/anonymized operations as described in the privacy policy.

## Reviewer test instructions

1. Install the ZIP as an unpacked extension or upload it as the package.
2. Open `https://applymate.site` and sign in with a test account.
3. Open a LinkedIn or Indeed job page and verify the Save to ApplyMate action, Popup, and Side Panel.
4. Open a Greenhouse, Lever, or Workday application page, open Side Panel → Form auto-fill, and click **Scan current page**.
5. For a custom employer domain, click **Allow access** in the Form auto-fill panel, then scan. Review and edit suggestions before clicking **Apply all to form**.
6. Verify that the extension never submits the application and that file uploads require the reviewer to choose a local file.
